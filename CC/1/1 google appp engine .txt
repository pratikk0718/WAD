========================================================
GOOGLE APP ENGINE INSTALLATION & SETUP USING PYTHON
========================================================

AIM:
----
Install Google App Engine and create Hello World
and simple web applications using Python.

========================================================
STEP 1: INSTALL GOOGLE CLOUD SDK
========================================================

Download and install Google Cloud SDK:

https://cloud.google.com/sdk/docs/install

After installation verify:

gcloud --version

========================================================
STEP 2: LOGIN TO GOOGLE CLOUD
========================================================

gcloud auth login

========================================================
STEP 3: CREATE GOOGLE CLOUD PROJECT
========================================================

gcloud projects create king-first-project-2026

========================================================
STEP 4: SET PROJECT
========================================================

gcloud config set project king-first-project-2026

========================================================
STEP 5: ENABLE APP ENGINE
========================================================

gcloud app create

Select Region:
Example:

6
(asia-south1)

NOTE:
-----
App Engine deployment may require billing account.

========================================================
STEP 6: CREATE PROJECT FOLDER
========================================================

mkdir python-app

cd python-app

========================================================
STEP 7: INSTALL REQUIREMENTS
========================================================

pip install flask

pip install gunicorn

========================================================
STEP 8: CREATE HELLO WORLD APPLICATION
========================================================

Create file: app.py

--------------------------------------------------------

from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return "Hello World from Google App Engine!"

if __name__ == '__main__':
    app.run(host='127.0.0.1', port=8080, debug=True)

from flask import Flask, request

app = Flask(__name__)

@app.route('/')
def form():

    return '''

    <h2>Student Form</h2>

    <form method="POST" action="/submit">

        Name:
        <input type="text" name="name">

        <input type="submit">

    </form>

    '''

@app.route('/submit', methods=['POST'])
def submit():

    name = request.form['name']

    return f"Welcome {name}"

if __name__ == '__main__':
    app.run(debug=True)
